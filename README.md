# Зарлиг 🎤

Монгол хэлээр **дуугаар болон бичгээр** команд өгч утсаа удирддаг Android туслах апп.

Нэг үг хэлэхэд тэр үйлдлийг хийнэ: залга, сануул, нээ, суулга, устга, цэвэрлэ.

---

## Юу хийдэг вэ?

| Команд (жишээ) | Үйлдэл |
|----------------|--------|
| `Болд руу залга` / `99112233 руу залга` | Утсаар залгана |
| `Facebook нээ` | Суулгасан апп нээнэ |
| `TikTok суулга` | Play Store-оос хайж суулгана |
| `TikTok устга` | Аппыг устгах цонх гаргана |
| `8 цагт сануул` | Сэрүүлэг тавина |
| `10 минутын таймер` | Таймер тавина |
| `Мессеж бич 99112233` | SMS цонх нээнэ |
| `Дуу чангал` / `Дуу намсга` / `Дуугүй бол` | Дуу тохируулна |
| `Wi-Fi нээ` / `Bluetooth нээ` | Тохиргоо нээнэ |
| `Цэвэрлэ` | Санах ойн цэвэрлэгээ нээнэ |
| `Цаг хэд вэ` | Цаг хэлнэ |
| `тусламж` | Бүх командыг харуулна |

## Технологи

- **Kotlin** + **Jetpack Compose** (орчин үеийн Android UI)
- **Android SpeechRecognizer** — монгол дуу таних (`mn-MN`)
- Min SDK 24 (Android 7.0+), Target SDK 34

## "Энгийн түвшин"-ий тухай

Энэ апп **root шаарддаггүй**. Android-ийн аюулгүй байдлын дүрмийн дагуу:
- Залгах, сэрүүлэг, апп нээх, дуу/тохиргоо → **шууд** хийнэ.
- Апп суулгах/устгах → систем нэг товч **баталгаажуулалт** асууна (энэ нь вирусаас хамгаалах Google-ийн дүрэм).

Бүрэн автомат (асуулгүй) суулгах/устгах нь Accessibility Service эсвэл root шаардана — хүсвэл дараа нэмж болно.

## Build хийх заавар (APK гаргах)

Энэ кодыг жинхэнэ утсан дээр суулгахын тулд `.apk` файл болгон хөрвүүлнэ.

### Хялбар арга — Android Studio (зөвлөж байна)

1. [Android Studio](https://developer.android.com/studio) татаж суулга.
2. `File → Open` → энэ төслийн хавтсыг сонго.
3. Gradle sync дуусахыг хүлээ (эхний удаа хэдэн минут).
4. Утсаа USB-ээр холбоод (эсвэл эмулятор) **Run ▶️** товч дар.
5. Апп утсан дээр суулгагдана.

### Командын мөрөөр (SDK суусан бол)

```bash
# Debug APK гаргах
./gradlew assembleDebug

# APK энд гарна:
# app/build/outputs/apk/debug/app-debug.apk
```

Энэ файлыг утас руугаа хуулж суулгаж болно (Settings → "Unknown sources" зөвшөөрөх шаардлагатай).

## Зөвшөөрлүүд

Апп эхлэхэд дараах зөвшөөрлийг асууна:
- **Микрофон** — дуугаар команд өгөх
- **Утас** — залгах
- **SMS** — мессеж илгээх
- **Харилцагч** — нэрээр залгах

---

## Цаашид нэмж болох зүйлс

- Accessibility Service (бүрэн автомат суулгах/устгах)
- Монгол дуу таних нарийвчлалыг сайжруулах
- Илүү олон команд (сэрүүлэг жагсаалт, тэмдэглэл, цаг агаар г.м.)
- Харанхуй горим (dark mode)
